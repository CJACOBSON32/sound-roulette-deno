Sound Roulette

Sound Roulette is a Discord bot designed to randomize a Discord server's soundboard at regular intervals using a user-uploaded library of sounds.

The goal of the project is to make server soundboards feel fresh and unpredictable by periodically rotating available sounds from a curated collection uploaded by users.

## Project Status

Sound Roulette is in the **very early stages of development**.

Many features are still experimental, incomplete, or subject to change. Expect breaking changes as the bot's structure, commands, permissions, and soundboard-management behavior evolve.

This version of the project is no longer maintained and should not be expected to run correctly.

## Planned Features

- Upload and manage a library of sounds
- Randomly select sounds from the uploaded library
- Rotate a Discord server's soundboard on a regular schedule
- Configure rotation intervals per server
- Support Discord slash commands for administration
- Provide safeguards for permissions, limits, and sound compatibility

## Requirements

- [Deno](https://deno.com/)
- A Discord bot token
- Access to a Discord server where you can invite and configure the bot
